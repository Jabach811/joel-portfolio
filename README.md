# Joel Abacherli — portfolio

An independent portfolio built in a new folder. No existing project was edited.

## Use and maintain

Open `dist/index.html`, or serve `dist` with a static server. The site has no build step or external runtime dependencies. Fonts and images are local.

- `dist/index.html`: page content and structure.
- `dist/style.css`: colors, responsive layouts, and motion.
- `dist/app.js`: project descriptions, categories, preview links, dialogs, filters, and motion controls.
- `dist/assets/`: copied project previews and licensed typefaces.
- `review/`: local inventory, capture utilities, browser checks, and screenshots. Excluded from publication and source push.

Only `dist` is published. Do not add agreements, reports, research files, or original project folders to it.

## Editorial decisions

Lead with Jack Klemm: confirmed by Joel as paid client work, with ongoing Phase 2 development. Other businesses are presented as independent concepts or visual studies; a working demo is not evidence of a client relationship. No revenue, conversion, or endorsement claims are made. Project-stage labels describe available artifacts, not formal sign-off.

The identity uses Joel's name rather than picking between the different studio names found in Business Assets. Contact email comes from his existing studio pages.

Screenshots of private website concepts are included as selected design examples, without linking visitors to access-restricted demos or changing those original sites' audiences. Client agreements and internal business documents are excluded.

## Visual direction

Big, rounded Bricolage Grotesque typography and DM Sans, a pale lilac project stage, vivid purple contact section, and yellow accents. Real project screens carry the visual weight. Each project retains its own palette. The hero gently floats; its pause control remembers the preference locally, and device reduced motion always takes priority. Native dialogs support Escape, keyboard focus containment, and focus return.
